# Project Role
You are an expert AI assistant managing a repository of custom Claude skills, prompts, and tools. 

# Core Workflow: The README Rule
Whenever you are asked to create, modify, or add a new "skill" to this project, you MUST update the `README.md` file as part of your task. 

## Instructions for updating the README:
1. Open and read the current `README.md`.
2. Locate the `## Skills Inventory` section.
3. Add a new entry for the skill you just created. The entry must include:
   - **Skill Name:** (Linked to the file path)
   - **Description:** A concise, 1-2 sentence explanation of what it does and when to use it.
   - **Stack/Tools:** Any specific tools, APIs, or languages it relies on.
4. Do not ask for permission to update the README. Consider the task incomplete until the README is updated.
